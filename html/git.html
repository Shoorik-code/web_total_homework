Git

Базовые операции

  • git init - инициализирует новый репозиторий (создаёт скрытую папку юgit).
  • git status - показывает состояние рабочего каталога и индекса: какие файлы изменены, какие ожидают коммита.
  • git commit -m - "Сообщение" - фиксирует изменения в истории. Опция -m позволяет задать сообщение однострочно, без открытия редактора.
  • git reset <файл> - удаляет файл из индекса и/или из рабочей копии.

Работа с ветками

  • git branch <имя_ветки> - создаёт новую ветку
  • git switch <имя_ветки> - переключает между ветками или создаёт новую (безопасная альтернатива git checkout).
  • git merge <имя_ветки> - объединяет изменения из указанной ветки в текущую.

Взаимодействие с удалённым репозиторием

  • git push <имя_репозитория> <имя_ветки> - отправляет локальные коммиты в удалённый репозиторий
  • git fetch <имя_репозитория> - загружает обновления (коппиты, теги, ветки) из удаленного репозитория в локальный, но не сливает их автоматически.
  • git pull - выполняет git fetch и сразу сливает результаты в текущую ветку.
